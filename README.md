# Blinkit Sales & Inventory Analysis

## Project Overview

This project analyzes Blinkit's sales, inventory, customer, and delivery data using SQL and Power BI.

## Objectives

- Identify inventory risks and products requiring reorder
- Identify dead stock
- Analyze customer purchase behavior
- Identify repeat purchases
- Validate order revenue
- Analyze late delivery impact
- Create an interactive sales dashboard

## SQL Analysis

The project includes the following SQL analyses:

1. Inventory Risk Detection
2. Dead Stock Identification
3. Customer Purchase Ranking
4. Repeat Purchase Analysis
5. Revenue vs Order Total Validation
6. Late Delivery Impact

## Dashboard

The Power BI dashboard contains:

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Monthly Sales
- Sales by Product
- Sales by Product Category
- Average Customer Spending by Segment
